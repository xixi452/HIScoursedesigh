## 二、5 分钟看懂

1. **范围**：3 个分系统——门诊挂号、门诊医生工作站（子集）、门诊药房（含划价收费）。
2. **闭环**：挂号扣号源 → 就诊 → 开方 → 收费 → 发药扣批次库存。
3. **数据**：10 个核心实体一个不少；排班号源是挂号的“库存”；药品库存必须带批次、效期、状态。
4. **合规**：身份证展示 `110101********1234`；库内只存脱敏串 + 哈希 + 后四位，不存明文。
5. **一致性**：扣号源、扣库存、收费、退号、退费、退药全部走事务；金额用“分”存整数。

## 四、SQL 运行方式

### 方式 1：sqlite3 命令行

```bash
sqlite3 his.db < 04_schema.sql
sqlite3 his.db < 06_seed_reference.sql
sqlite3 his.db "PRAGMA foreign_key_check;"
```

### 方式 2：Python

```python
import sqlite3

con = sqlite3.connect("his.db")
con.executescript(open("04_schema.sql", encoding="utf-8").read())
con.executescript(open("06_seed_reference.sql", encoding="utf-8").read())
print(con.execute("PRAGMA foreign_key_check").fetchall())
con.close()
```

> 应用每次连接数据库都要执行 `PRAGMA foreign_keys = ON;`，否则外键不生效。
