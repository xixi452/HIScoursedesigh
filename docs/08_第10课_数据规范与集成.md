## 一、三项产出（第 10 课作业①）

| 产出 | 落点 | 说明 |

| CSV 批量导入（服务端校验 + 错误明细） | `routers/drugs.py`（药品）、`routers/import_patients.py`（患者） | 逐行校验，错误行不影响合法行；身份证脱敏入库 |

## 二、医院数据三道规矩（第 10 课行业规矩）

1. **编码**：诊断用 ICD-10（如 K35.8 急性阑尾炎），统计/医保/科研全靠编码——汉字写法千奇百怪，编码只有一种。
2. **字典**：药品档案五要素——通用名 + 商品名 + 规格 + 剂型 + 医保类别；医保报销按通用名和类别走，与商品名无关。
3. **交换协议**：HL7 / FHIR（本期只了解，不实现）。

> 本系统 `drugs` 表已具备五要素：`generic_name`（通用名）、`trade_name`（商品名）、`spec`（规格）、`dosage_form`（剂型）、`insurance_type`（医保类别）。导入 CSV 亦按五要素 + 编码 + 单价 + 库存校验。

## 三、药品目录与真实数据对齐

`药品数据.xlsx`（178110 行 × 40 列，湖南省医保目录）关键列与本系统字段映射：

| Excel 列 | 本系统字段 |
|---|---|
| 药品通用编码 | `drug_code` |
| 药品通用名称 | `generic_name` |
| 商品名 | `trade_name` |
| 药品注册规格 | `spec` |
| 通用目录剂型 | `dosage_form` |
| 甲乙标志 | `insurance_type`（甲类/乙类） |
| 标准单价 | `price_cents`（元→分） |

`gen_drugs_csv.py` 从该表采样生成 100 条合法 + 6 条脏数据（缺编码/缺规格/非法单价/非法医保类别/非法库存/编码重复），用于演示服务端校验与错误报告。

## 四、常见坑（FAQ 落地）

- **CSV 乱码**：Excel 导出常是 GBK，导入时自动检测（UTF-8 BOM → UTF-8 → GBK 回退）。
- **审计拖慢系统**：写操作加一条日志开销可忽略；**合规优先，别为性能砍审计**。
- **ICD-10 不用背**：知道存在、结构是「字母 + 数字」即可，需要时让 AI 生成示例。
