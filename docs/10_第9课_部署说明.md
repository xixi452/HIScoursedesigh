# 第 9 课 · 部署与运维（交付说明）

> 角色：DevOps 工程师　·　目标：拿到一个「手机也能打开」的公网 HTTPS 地址。
> 免费层方案：前端 Vercel，后端 Render，数据库 SQLite（或免费 PostgreSQL）。

## 一、产出文件（已在仓库 / 03/deploy）

| 文件 | 作用 | 关键行 |
|---|---|---|
| `backend/Dockerfile` | 后端镜像 | `pip install` → `COPY 后端代码` → `seed_all.py && uvicorn` |
| `frontend/Dockerfile` | 前端镜像 | `node 构建` → `nginx 托管`（`VITE_API_BASE` 构建时注入） |
| `docker-compose.yml` | 一条命令起三容器 | `services: backend / frontend` + SQLite `volume` 持久化 |
| `.github/workflows/ci.yml` | 推送即测试 | `pytest -q` + `npm run build`，测试不过不部署 |
| `.env.example` | 变量名模板 | 只提交变量名，真实值进 `.env`（已忽略） |
| `backend/seed_all.py` | 启动种子 | 建表 + 5 账号 + 排班/药品/库存 + 患者（幂等） |

## 二、部署四步套路（换平台不换套路）

1. **推代码到 GitHub**：`git push`（仓库 https://github.com/xixi452/HIScoursedesigh.git）
2. **云平台关联仓库**：Vercel 挂前端，Render 挂后端
3. **配置构建命令与环境变量**（见下表）
4. **自动部署拿 HTTPS 地址**，手机热点验证

## 三、云端环境变量（在后台配，绝不写进代码仓库）

| 平台 | 变量 | 值示例 |
|---|---|---|
| Render（后端） | `HIS_JWT_SECRET` | 32+ 字符随机串 |
| Render（后端） | `HIS_ID_SALT` | 随机加盐串 |
| Render（后端） | Start command | `python seed_all.py && uvicorn main:app --host 0.0.0.0 --port 8000` |
| Vercel（前端） | `VITE_API_BASE` | 后端公网地址，如 `https://his-mvp.onrender.com` |

> Render 后端需设 Build command：`pip install -r requirements.txt`；根目录选 `backend`。
> Vercel 前端：Framework 选 Vite，Root Directory 选 `frontend`。

## 四、高频坑（第 9 课 FAQ 落地）

| 现象 | 原因 | 处理 |
|---|---|---|
| Vercel 前端接口 404 | 环境变量没配（`VITE_API_BASE`）或跨域 | 查 Vercel 环境变量 + 后端 CORS 已允许来源 |
| Render 免费实例打不开 | 免费层休眠 | **演示前提前 10 分钟访问一次预热** |
| 本地 Docker 能跑、云上不行 | 缺依赖 / 数据库没持久化 / 端口不同 | 对比本地与云上日志；免费层 SQLite 为临时盘，重启丢数据（可换 PostgreSQL） |

## 五、本地一键启动（验证 Dockerfile 正确）

```bash
cd his-mvp
docker compose up --build
# 浏览器打开 http://localhost:5173（前端），后端 http://localhost:8000/docs
```

> 部署报错 90% 出在配置文件。这些文件可以让 AI 生成，但**逐行看懂**才敢交——看懂了，报错才知道改哪一行。

## 六、⚠️ 需要你手动完成的操作（我无法代做）

1. **推代码**：把 `his-mvp`（含 Dockerfile/docker-compose/.github/workflows/.env.example）推送到 GitHub 仓库。
2. **Vercel**：新建项目关联该仓库 → 选 `frontend` → 配 `VITE_API_BASE`。
3. **Render**：新建 Web Service 关联仓库 → 根目录 `backend` → 配环境变量 + 启动命令。
4. **预热**：拿到 HTTPS 地址后，答辩前提前 10 分钟用手机热点访问一次唤醒实例。
